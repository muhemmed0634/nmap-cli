how to install on linux: 
1.install nmap :
Install Nmap on Linux using your distribution's package manager for the easiest setup.  For Debian-based systems like Ubuntu and Debian, update your package list and install the tool with:

sudo apt update
sudo apt install nmap

For Red Hat-based systems like CentOS and RHEL, use the appropriate command for your version:

# CentOS 7 and older
sudo yum install nmap

# CentOS 8+, RHEL 8+, Fedora, AlmaLinux, Rocky Linux
sudo dnf install nmap

# For Arch Linux and derivatives, use:

sudo pacman -S nmap
